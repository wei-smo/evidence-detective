# 公开发布范围

发布目标：GitHub `wei-smo/evidence-detective`，由用户明确选择公开。快照包含当前产品源码、测试、部署脚本、角色素材与字体许可、研究方法、提示词和脱敏后的可见开发对话。

## 必须自行配置

复制 `.env.example` 为本机 `.env.local`，填写自己的 `YUANBAO_SEARCH_API_KEY` 与 `REASONING_API_KEY`。模板中的服务地址、模型名是非敏感配置；密钥留空。对外监听还需要自己的 `APP_ACCESS_TOKEN`，具体见 [部署说明](DEPLOYMENT.md)。

## 不进入仓库的材料

- `.env.local`、其他本地环境文件、密钥和访问口令。
- `data/` 的原始调查和审计、`artifacts/` 的本机验证产物、`.tmp/` 与缓存。
- 开通确认、账单或账号截图；根目录的临时图片。
- 工具输入输出、隐藏推理、系统/开发者提示、其他聊天或本机凭据。

现有六角色PNG、已使用的原图及映射保留；不重新生成或加工角色。字体随附原SIL OFL许可。历史验收文档中的本机证据路径可保留追溯，但对应私有运行目录不会随仓库公开；历史通过不等于本次重新执行。

## 对话脱敏与真实性

归档仅提取指定开发会话中的可见用户/助手文字，按时间排序。移除自动注入的浏览器上下文、图片数据和本机附件路径，替换已知密钥与可识别凭据，不公开原始工具日志。保留历史失败、中断与当时的限制说明，不把它们改写成成功训练。

当前版本没有模型权重训练，见 [方法与训练说明](TRAINING_AND_METHODS.md)。公开对话用于理解设计和工程迭代；其中历史助手观点应以实际代码与证据复核。

## 发布前验证

发布副本经过已知密钥精确扫描、常见凭据格式扫描、发布路径审查和干净配置验证。只发布允许清单内的文件。原始密钥文件保留在本机，不进入Git对象和压缩包。

实际执行结果与独立审查结论见 [发布验证记录](RELEASE_VERIFICATION.md)。Docker上下文已保留运行所需角色PNG；没有实际Docker构建时明确记录NOT_RUN。
