# 部署与安全说明

## 本地交付

推荐先使用本地网页验收，不需要数据库、Node 构建流程或 Docker。

```powershell
python -m evidence_detective.server --host 127.0.0.1 --port 8765
```

服务终止用所在终端的 Ctrl+C。报告保存在 `data/investigations/`，重启后仍可从历史读取。

## 可部署包

源码可部署到带 Python 与 curl 的 Linux/Windows 服务器。`Dockerfile` 为可选构建说明；本机尚未验证 Docker 构建，不标为已部署。

```text
docker build -t evidence-detective .
docker run --env-file <仅包含必要变量的私有环境文件> -p 127.0.0.1:8765:8765 -v <持久数据目录>:/app/data evidence-detective
```

必须显式配置至少 16 字符的 `APP_ACCESS_TOKEN` 才允许非回环监听。在 HTTPS 反向代理后使用，确保 SSE 不被缓冲；代理应配置连接/请求时限与请求频率限制。页面“访问口令”只在当前标签页 sessionStorage 保存，不通过 URL 传递。

容器使用非root的 `detective` 用户；绑定宿主数据目录时，请确保该目录可由容器用户写入，否则调查报告和审计无法落盘。不要以将密钥写入镜像或提交仓库的方式解决配置问题。

这是单工作空间参赛版本：同一口令的访问者可看到该空间历史，并添加复核记录。它不是隔离用户数据的多租户产品。不要向不受信任人员开放，不要把敏感调查与公开演示混在一个实例。

## 密钥与日志

- `.env.local`、环境变量仅由后端读取；静态服务仅白名单开放 `index.html`、`app.js`、`style.css`。
- 元宝密钥通过 curl 标准输入配置传递，不出现在进程命令行、浏览器或请求审计头中。
- 原始审计记录包含用户问题、查询和搜索返回正文，**不是无敏感数据的空日志**，仅保留在服务端。备份、分享前检查内容和版权，不能上传整份工作区。
- 推理由本地 `.env.local` 决定，代码不硬编码供应商。公开模板保留 `https://api.deepseek.com` / `deepseek-flash` 并设置 `REASONING_ENABLED=1`，但两个API密钥均为空。部署者必须填写自己的元宝服务API Key与DeepSeek API Key，才具备完整调查所需配置；密钥不会由仓库提供，不自动接入其他模型。
- 导出报告包含原始链接、逐字证据、手动标注与时间。操作者署名不等于身份认证，片段匹配也不等于语义正确。

## 网络边界

搜索只发送到元宝 SearchPro。来源读取仅访问已发现 URL：限制 HTTP/HTTPS、端口、拒绝私网 IP、解析后固定公网地址、每次重定向重新校验；每轮最多读取 4 个候选来源、全程最多 8 个、每页最多 400KB。

仍存在的限制：DNS 解析与网络超时可能使总耗时超过目标；部分站点有反爬、需要 JS 或返回压缩/PDF，当前可能无法读取。HTTP 200 也可能是机器人验证页，不能仅据此宣布“证据核验成功”。

搜索请求上限默认 6 次，流程时间预算默认 300 秒是调度预算，不是外部 I/O 严格硬实时承诺。模型单次请求最多 75 秒。最多同时运行两项调查。对外暴露前还需部署侧限流、完整安全审计与真实多用户压测。
