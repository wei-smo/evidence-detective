# 脱敏开发对话

此目录保存三个指定会话中的可见用户与助手文字：最初开发、接手修复、方法梳理与发布讨论。它们是项目设计和工程迭代材料，不是SFT/RL训练记录或已标注的训练数据。

归档由会话读取接口逐页提取，按时间排序，只保留 `userMessage` 与 `agentMessage`。不包含系统/开发者指令、隐藏推理、工具调用/响应、图片数据或其他会话。自动附带的浏览器上下文、本机附件路径和可识别凭据经过清理。进行中的轮次只保存当时可读取内容，不能解读为工作已经结束。

历史说法可能被后续纠正；历史成功、失败、服务阻塞均保留。会话里旧的工具引用标记可能无法在GitHub打开，论文入口请使用 [方法说明](../TRAINING_AND_METHODS.md) 中的正式链接。

- [最初开发](01-original-development.md)。
- [接手修复](02-takeover-repair.md)。
- [研究方法与发布讨论](03-methods-and-release.md)。
- 同名 `.jsonl` 提供便于程序读取的消息记录；`manifest.json` 记录来源、条数、导出时间与脱敏范围。

本目录不保证对话中的每条助手陈述正确，也不将助手自评作为金标准。若用于未来训练，必须另行做来源、标签和数据划分审核。
